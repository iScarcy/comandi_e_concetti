first = recupera il primo elemento di un observable

    from(this.clients)
    .pipe(first())
    .subscribe(console.log);

last  = recupera l'ultimo elemento di un observable

filter = permette di impostare un filtro per selezionare degli elmenti

    from(this.clients)
    .pipe(filter(e => e.enabled === false))
    .subscribe(console.log);

map = permette di modificare un flusso di risposta dell'observable mappando gli elementi restituiti con altri (si può fare una selezione degli altrimenti restituiti)

 from(this.clients)
    .pipe(
      filter(e => e.enabled === false),
      map(e => e.Name)      
      )
    .subscribe(console.log);

timer = permette di generare un observable dopo un tot di secondi

  const $firstRequest = timer(3000)
    .pipe(
      map( e => "prima richiesta")
    );

    const $secondRequest = timer(10000)
    .pipe(
      map( e => "seconda richiesta")
    );

concat = concatene due richieste, esegue prima una e poi l'altra

    concat($firstRequest,$secondRequest)
    .subscribe(message => console.log(message));

*****************************	FLEX LAYOUT *********************************

PER ABILITARLO: npm install @angular/flex-layout

es html: 
	<div class="flex-container">
		<div class="flex-item"></div>
	</div>
	
-> regole css interessanti del flex-container<-
- display: flex
- flex-wrap: (gli elmenti vanno a capo/cambiano in base le dimensioni dello schermo)
- flex-direction: allineamento orizionatale (row) o verticale (coloum) degli elmenti interni al container
- justify content: space arround (spazio intorno gli item)
		   flex-strart (gli elmenti sono orienti sul lato sinistro perché la spaziatura è orientata sul lato destro)
		   frex-end (elementi orientati sul lato detro)
		   center (elementi orientati al centro)
		   space-between (spaziatura tra gli oggetti, gli elementi iniziano e finisco all'estremita) 	
- align-items: 	flex-star (default, elementi posizionati nella parte superiore)
		flex-end  (elementi posizionati nella parte inferiore)
		center (elementi posizionati al cento del contenitore)
		stratch (gli ementi partiranno dalla parte superiore del container per arrivare gino alla  fine)
		   

->regole interessanti per gli items <-

- align-self (stesse proprietà di align-items del container ma permette di specificare comportamenti sui singoli item)
- order (permettere di dare un ordine agli elmeni diverso dal rendering dal html, di base tutti gli elmenti hanno order 0)
- flex-grow (di tutto lo spazio che c'è, a prescindere dal cotenuto, dai maggiore priorità a quegli elmenti che hanno un flex-grow più alto. Per priorità si intente posizionamento a sinistra e dimentisioni nella riga)
- flex-shrink (determina la velocità di un elemento nel ridursi durante la riduzione dello schermo, più alto è il valore più veloce si ridurrà l'elementi )
- flex-basis (dimension del item, proporzionata agli altri)
