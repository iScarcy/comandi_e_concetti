IMPLEMENTAZINOE ANGULAR DELLA LIBRERIA REDUX PER LA GESTIONE DEGLI STATI DI UN'APPLICAZIONE

COS'è E PRECHé NE ABBIAMO BISOGNO ? 
-> in un applicazione che non implementa la gestione degli stati, ogni dato che il frontend deve mostrare in pagina va recuperato tramite il backend e quando c'è un aggiornamento 
	ogni sezione della pagina coinvolta con quell'aggiornamento deve essere aggiornata. 
->	La gestione degli stati, consiste nella gestione di una specie di database in memoria del frontend che si sincronizza con il backend in backgroud senza disturbare le azioni del frontend migliorandone le prestazioni.
	Uno degli obiettivi è ridurre le chiamate http ripetute tra frontend e backend

				  ma dando uno stato in input e un azione, calcola una nuova versione dello stato e la in output
				  
				  

esempio di crerazione di un reducer
				  
export interface AuthState {
    user: User
}

export const initialAuthState: AuthState = {
    user: undefined
}
 

export const authReducer = createReducer (
    // valore iniziale
	initialAuthState, 
    //azione che si scatena al verificarsi della login 
	on(AuthActions.login, (state, action) => {return {
        user: action.user
    }})
)

Diagramma:

Component -> Action -> Reducer -> Store -> Selector -> Component (Again)
				|	
				|
				Effects

Un componente può avedere delle azioni che lanciano dei reducer per aggiornare lo store e lo stati. 
I Selector sono semplicemente dei subscriber tramite cui leggere i dati dello store.
Gli effect hanno un ruolo importante perché sono loro che si occupano di interaggire con i servizi http e passare i dati alle action


Actions describe unique events that are dispatched from components and services -> Le actions descrivono eventi unici inviati da componenti e servizi
State changes are handled by pure functions called reducers that take the current state and the latest action to compute a new state. -> I reducers sono funzioni che prendono lo stato attuale e l'ultima azione invocata e calcolano un nuovo stato 
Selectors sono funzioni usate per selezionare, derivare e comporre porzioni dello state
Lo state è accessibile tramite lo store, un observable dello state e degli obsevable delle azioni
